# Krasnoludy

Podpowiedzi dla emotek Krasnoludow z Twierdz Gor Starego Swiata. Wpisz
poczatek komendy i wcisnij **Tab** - plugin dopelni ja do pelnej emotki.

## Co potrafi

- **Dopelnianie Tabem** - `gpo` + Tab daje `gpoczysc brode`, `gppo` + Tab
  przelacza miedzy `gppowitaj`, `gppozegnaj`, `gppogladz brode` i reszta.
- **Pelne warianty** - emotki ze stalym dopelnieniem podpowiadaja sie w calosci,
  np. `gpwytrzyj usta`, `gpwytrzyj brode`, `gpwytrzyj usta i brode`.

## Instalacja

1. W menedzerze pluginow Arkadia Web Client dodaj plugin **Krasnoludy**.
2. Wpisz `gp` i wcisnij Tab, zeby sprawdzic, czy dziala.

## Prywatnosc

Plugin nic nie zapisuje i nie wykonuje zadnych zapytan sieciowych.
